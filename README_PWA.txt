Engineer Pay Log V8.3

Production release.

This release introduces a redesigned dashboard, bottom navigation, refined Shift History, streamlined Settings, improved mobile form sizing, dark-mode polish, and other interface refinements.

No pay calculation rules were changed in this update.

Deployment:
For an existing production repository, only index.html and service-worker.js need to be replaced. All other app-shell files are unchanged from V8.2.4.
